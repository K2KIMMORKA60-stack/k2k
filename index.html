    Comment lire K2K

    • Institutions : chaque vendredi, la CFTC publie les positions des banques et des fonds sur les contrats à terme (données du mardi). C'est le biais de fond, pour plusieurs semaines.
    • Graphique : K2K repère les cassures de structure (BOS, CHoCH), les order blocks, les FVG, les chasses de liquidité et les volumes anormaux. C'est le timing.
    • Quand les deux sont d'accord, le signal est plus solide. Quand ils divergent, la prudence est de mise.
    • NAS100 n'a pas de flux de prix gratuit : exporte tes bougies depuis MT5 (clic droit sur le graphique, Bougies, Exporter) ou TradingView (menu, Exporter les données du graphique), puis importe le fichier.
