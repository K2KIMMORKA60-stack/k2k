# K2K

Application web installable (PWA) qui suit les traces des banques et des fonds sur XAUUSD, NAS100 et BTC.

- **Institutions** : rapport COT hebdomadaire de la CFTC (or COMEX, E-mini Nasdaq-100, Bitcoin CME).
- **Graphique** : détection SMC (BOS, CHoCH, order blocks, FVG, chasses de liquidité, volumes anormaux).
- Prix en direct : Binance (BTCUSDT, PAXGUSDT pour l'or). NAS100 : import d'un export MT5 ou TradingView.

Aide à la décision uniquement, pas un conseil financier.

Installation : ouvrir https://k2kimmorka60-stack.github.io/k2k/ sur le téléphone, puis « Ajouter à l'écran d'accueil ».
